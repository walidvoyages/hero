# Walid Voyages — Omra 19 Octobre 2026

Animated one-page HTML/CSS/JS storytelling experience:
agency → Tunis-Carthage airport → Nouvelair flight → Madinah → transfer → Makkah → trip summary.

## Deploy on GitHub Pages
1. Upload `index.html`, `styles.css`, and `script.js` to a GitHub repository.
2. Settings → Pages → Deploy from branch → `main` → `/root`.
3. Open the generated GitHub Pages URL.

## Notes
- The project uses remote web images, so an internet connection is required.
- Replace any image URL directly in `index.html` if you want a different visual.
- Text is RTL and responsive for mobile / desktop.
